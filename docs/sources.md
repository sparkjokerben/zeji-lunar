# 数据来源与古籍出处

本网站所有黄历内容均依据中国古籍与传统通书体系，计算由开源库 **lunar-typescript**（MIT，作者 6tail，v1.8.6）与本站自有模块（`shared/`）完成；**全站不包含任何西方占星、西方数字命理内容**。

| 数据 | 古籍出处 | 载体 |
|---|---|---|
| 公历↔农历转换、节气 | 紫金山天文台《中国天文年历》、香港天文台公历农历对照表体系 | lunar-typescript 算法依据 |
| 宜忌、值神、冲煞、建除十二值星、九星、二十八宿、吉神方位、黄黑道时辰 | 传统通书体系：《协纪辨方书》（乾隆钦定）、《玉匣记》、《象吉通书》 | lunar-typescript |
| 八字、十神、日主、喜用神（强弱取用为本站自实现简化逻辑） | 子平法：《渊海子平》《三命通会》《子平真诠》；《滴天髓》 | lunar-typescript + 本站 `personal.ts` |
| 五行五色（幸运色） | 《尚书·洪范》"一曰水，二曰火，三曰木，四曰金，五曰土"及五行五色配属 | 本站 `elements.ts` |

| 彭祖百忌 | 彭祖百忌日口诀（传统择日忌用） | lunar-typescript |

## 口径说明

- **农历日期**按传统历法（正月初一为岁首）；**生肖**按八字年支（立春为岁首），两者口径不同属正常，本站生肖统一取立春口径。
- **时辰吉凶**按黄黑道十二神（青龙、明堂、金匮、天德、玉堂、司命为黄道，余为黑道），见《协纪辨方书》。
- **时辰未知**按午时计；**23 时晚子时**按当日八字计（lunar-typescript 默认口径）。
- **日主强弱与喜用神**采用简化扶抑法（参考《子平真诠》论用神），属民俗简化算法，非专业命理。
- 设置同步使用简单 token 鉴权（单用户场景的弱保护，非安全边界）。
